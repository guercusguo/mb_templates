MapLibre GL JS templates

Frequently used snippets, each with a runnable example. No account or access token is needed.

  • Map load - Bounded map, navigation control, return-to-extent button (js/mapload.js)
  • Layer load - GeoJSON polygons and points, custom marker image, 3D terrain, hillshade, sky (js/layerload.js)
  • Style switch - Basemap switch that adds sources and layers again (js/styleswitch.js)
  • Scroll sync - Map camera following the sections of a scrolling page (js/scrollsync.js)
  • Popup - Popup on click built from feature attributes (js/htmlpopup.js)
  • Cluster load - Clusters drawn as donut charts by category, click to zoom (js/clusterload.js)
  • Timeline - Year slider and month buttons filtering a layer (js/timeline.js)
  • Compare - Two maps with a swipe handle (js/compare.js)
